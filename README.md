Репозиторий Frame-by-Frame Video Player
Описание
Frame-by-Frame Video Player – это набор консольных утилит на 8 языках программирования для покадрового просмотра видеофайлов. Программа извлекает кадры из видео, преобразует их в ASCII-графику (оттенки серого) и отображает в терминале с возможностью управления: переключение кадров, пауза, воспроизведение и настройка скорости.

Возможности
Покадровый просмотр – переключение вперёд/назад с помощью клавиш ←/→ (или a/d).

Автовоспроизведение – нажмите Space для запуска/остановки автоматического перелистывания кадров.

Настройка скорости – клавиши +/- для увеличения/уменьшения FPS (кадров в секунду) при автовоспроизведении.

Вывод информации – номер текущего кадра, общее количество кадров, FPS видео, размер кадра.

Цветной вывод – в терминалах с поддержкой ANSI оттенки серого отображаются разными цветами для лучшей читаемости.

Работа с файлами – поддержка популярных форматов (MP4, AVI, MOV, MKV) через ffmpeg.

Требования
Для работы программы необходим ffmpeg (установленный в системе и доступный в PATH). FFmpeg используется для декодирования видео и извлечения кадров в сыром виде (RGB24). Программа не требует других библиотек, только стандартные средства языка для вызова внешних процессов и работы с терминалом.

Установка ffmpeg
Windows: скачайте с ffmpeg.org и добавьте в PATH.

macOS: brew install ffmpeg

Linux: sudo apt install ffmpeg (Debian/Ubuntu) или аналоги.

Установка и запуск
Каждый файл является самостоятельной программой. Для запуска необходима соответствующая среда выполнения.

Язык	Зависимости	Команда запуска
Python	Python 3.8+ (только стандартная библиотека)	python player.py <video_file>
JavaScript	Node.js 14+ (только стандартные модули)	node player.js <video_file>
TypeScript	Node.js + ts-node (только стандартные модули)	ts-node player.ts <video_file>
Go	Go 1.18+ (только стандартная библиотека)	go run player.go <video_file>
Java	JDK 11+ (только стандартная библиотека)	javac Player.java && java Player <video_file>
C#	.NET SDK 6.0+ (или csc)	csc Player.cs && Player.exe <video_file>
PHP	PHP 8.0+ (только стандартные функции)	php player.php <video_file>
Ruby	Ruby 2.7+ (только стандартная библиотека)	ruby player.rb <video_file>
Использование
text
player <video_file> [--width W] [--height H] [--fps N]
video_file – путь к видеофайлу.

--width W – ширина ASCII-вывода в символах (по умолчанию 80).

--height H – высота ASCII-вывода в символах (по умолчанию 40, будет подогнана под пропорции).

--fps N – скорость автовоспроизведения (кадров в секунду, по умолчанию 5).

Управление во время просмотра:

← или a – предыдущий кадр

→ или d – следующий кадр

Space – пауза/возобновление автовоспроизведения

+ или = – увеличить скорость автовоспроизведения

- или _ – уменьшить скорость автовоспроизведения

q или Esc – выход

Пример:

bash
python player.py video.mp4 --width 100 --fps 10
Как это работает
Программа использует ffmpeg для извлечения кадров из видео в формате RGB24 (сырые пиксели). Каждый кадр преобразуется в оттенки серого, затем уменьшается до заданных размеров (ASCII-сетка). Для каждого пикселя выбирается символ из набора, представляющего градации серого (например, .,:;ox%#@). Полученная текстовая картинка выводится в терминал с обновлением позиции курсора (ANSI-коды). Управление клавишами реализовано через неблокирующий ввод.

Особенности реализаций
Python – использует subprocess, struct для разбора сырых данных, termios для неблокирующего ввода.

JavaScript – использует child_process.spawn, Buffer для данных, readline для режима raw.

TypeScript – строгая типизация, аналогично JavaScript.

Go – os/exec, encoding/binary, горутины для асинхронного чтения ввода.

Java – ProcessBuilder, ByteBuffer, NIO, jline не используется (ручной ввод через System.in в отдельном потоке).

C# – Process, BinaryReader, Console.KeyAvailable для неблокирующего ввода.

PHP – proc_open, unpack, stream_select для неблокирующего ввода.

Ruby – Open3, StringIO, IO.select для ввода.
